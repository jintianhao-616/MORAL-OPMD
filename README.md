# MORAL-OPMD

Multimodal Risk-Aware Learning for Oral Potentially Malignant Disorders (OPMD)

## 🔍 Overview
This repository provides the implementation of MORAL-OPMD, a multimodal deep learning framework integrating white-light imaging (WLI), autofluorescence imaging (AFI), and structured clinical information for oral epithelial dysplasia (OED) grading and clinical risk stratification.

## 📊 Tasks
- Five-class OED grading (0–4)
- Binary risk stratification (low-risk vs. high-risk)

## 🧠 Model
The framework integrates:
- WLI (white-light imaging)
- AFI (autofluorescence imaging)
- Structured clinical text

A multimodal fusion strategy is used to jointly perform grading and risk prediction at the patient level.
